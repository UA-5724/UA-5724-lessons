# Домашнє завдання №1: Робота з Git та розгалуженнями

Цей репозиторій призначений для виконання практичного завдання з курсу **learncsh**. Ви навчитеся працювати з гілками, фіксувати зміни та створювати Pull Request.

---

## 🎯 Мета завдання

Пройти інтерактивний курс з візуалізації команд Git та надіслати результати на перевірку.

---

## 🛠 Кроки виконання

### 1️⃣ Проходження тренажера

Відкрийте посилання: **[Learn Git Branching (Українська версія)](https://learngitbranching.js.org/?locale=uk)**

Необхідно пройти всі рівні:

* Основні
* Віддалені репозиторії
* Інші доступні розділи

Зробіть скріншоти проходження рівнів.

> 💡 Порада: можна зробити скріншот фінального меню, де видно позначки виконаних завдань.

---

### 2️⃣ Підготовка локального репозиторію

Склонуйте проект на свій комп'ютер:

```bash
git clone https://github.com/UA-5724/UA-5724-lessons.git
cd UA-5724-lessons
```

---

### 3️⃣ Робота з гілками

Створіть власну гілку для виконання завдання.
Замініть `nickname` на ваш логін у GitHub:

```bash
git checkout main
git pull origin main
git checkout -b hw01/nickname
```

---

### 4️⃣ Додавання результатів

1. Перейдіть до папки `hw/hw01/`.
2. Створіть директорію з вашим нікнеймом.
3. Скопіюйте туди скріншоти.

Очікувана структура файлів:

```text
learncsh/
└── hw/
    └── hw01/
        └── <ваш_нікнейм>/
            ├── level1.png
            ├── level2.png
            └── ...
```

---

### 5️⃣ Коміт та відправка змін

Зафіксуйте зміни та відправте гілку у віддалений репозиторій:

```bash
git add .
git commit -m "feat: додано скріншоти виконаного ДЗ01 від <ваш_нікнейм>"
git push origin hw01/nickname
```

---

### 6️⃣ Створення Pull Request (PR)

1. Перейдіть на сторінку репозиторію **learncsh**.
2. Натисніть **"Compare & pull request"**.
3. Перевірте:

   * Base branch: `main`
   * Head branch: `hw01/nickname`
4. Назва PR:

   ```
   HW01: Прізвище Ім'я (nickname)
   ```
5. Натисніть **"Create pull request"**.

---

## ⚠️ Важливі зауваження

* Не вносьте зміни в папки інших студентів.
* Використовуйте латиницю в назвах файлів та папок.
* Не створюйте PR у чужі гілки.
