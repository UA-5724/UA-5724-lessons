# Console Application – Practice Tasks (C#)

## 📌 General Task

Create a **Console Application** project in **Visual Studio**.

In the `Main()` method, write code to solve the following tasks.

---

## 1️⃣ Arithmetic Operations

- Define integer variables `a` and `b`.
- Read values `a` and `b` from the console.
- Calculate:
  - `a + b`
  - `a - b`
  - `a * b`
  - `a / b`
- Output all results to the console.

---

## 2️⃣ Simple Question

- Output the question:  
  **"How are you?"**
- Define a string variable `answer`.
- Read the value of `answer`.
- Output:  
  **"You are (answer)"**

---

## 3️⃣ Working with char

- Read **3 variables** of type `char`.
- Output the message:  
  **"You entered (first char), (second char), (third char)"**

---

## 4️⃣ Boolean Expression

- Enter **2 integer numbers**.
- Check if they are **both positive**.
- Use a `bool` expression.
- Output the result to the console.

---

## 5️⃣ Square Calculations

- Define an integer variable `a` (side of the square).
- Read the value from the console.
- Calculate:
  - Area of the square
  - Perimeter of the square
- Output the results to the console.

---

## 6️⃣ Name and Age Interaction

- Define:
  - `string name`
  - `int age`
- Output the question:  
  **"What is your name?"**
- Read the value of `name`.
- Output the next question:  
  **"How old are you, (name)?"**
- Read the value of `age`.
- Output the complete information (name and age).

---

## 7️⃣ Circle Calculations

- Read a `double` number `r` (radius of a circle).
- Calculate:
  - Length: `l = 2 * π * r`
  - Area: `S = π * r * r`
  - Volume: `V = 4/3 * π * r * r * r`
- Output all results to the console.

---

## ✅ Expected Result

The program should:
- Correctly read input values
- Perform calculations
- Display formatted output in the console
